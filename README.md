# Numesh Ravindra Photography

A premium, modern photography portfolio website for **Numesh Ravindra**, a professional photographer based in **Mawanella, Sri Lanka**.

This portfolio showcase is built with **Next.js** and **Vanilla CSS**, featuring a fluid responsive grid, immersive visual galleries, and interactive features.

## 📸 Photography Specialties
* **Weddings:** Capturing timeless love stories and emotional celebrations.
* **Wildlife:** Documenting raw, majestic moments in nature.
* **Events:** Freezing high-energy, memorable occasions.
* **Portraits:** Creative, expressive, and detailed character portraits.

## ✨ Features
* **Dynamic Portfolio Gallery:** Smoothly filter photography by category (Weddings, Wildlife, Events, Portraits).
* **Interactive Lightbox:** Click on any photo to open a fullscreen preview featuring details like lens type, location, and capture settings.
* **Editorial About Page:** A clean biographical narrative highlighting Numesh's creative philosophy.
* **Services & Packages:** A transparent pricing guide showcasing wedding packages, wildlife sessions, event coverages, and portrait shoots.
* **Interactive Contact & Booking:** A clean booking inquiry form alongside a dynamic FAQ accordion.
* **Aesthetic Design:** Sleek typography, subtle micro-animations, glassmorphic navigation, and full mobile responsiveness.

## 🛠️ Technology Stack
* **Framework:** Next.js (with React)
* **Styling:** Vanilla CSS (custom properties, variables, and responsive layouts)
* **Icons:** Lucide React
* **Assets:** High-resolution optimized photography links

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser to view the portfolio.

### 3. Build for Production
```bash
npm run build
```
